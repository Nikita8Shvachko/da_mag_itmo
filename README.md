## Швачко Никита
Репозиторий с решениями лабораторных работ по курсу «Анализ данных»

## 🛠️ Требования

- Python 3.10+
- Зависимости — в `requirements.txt`:

```
numpy>=1.24
pandas>=2.0
matplotlib>=3.7
scikit-learn>=1.3
scipy>=1.10
tabulate>=0.9
jupyter>=1.0
```

Установка:

```bash
python -m venv .venv
source .venv/bin/activate        # Linux/macOS
# .venv\Scripts\activate         # Windows
pip install -r requirements.txt
```

## 🚀 Запуск

```bash
jupyter lab
```

Открыть нужный ноутбук в `labs/<lab_name>/solution.ipynb`.
